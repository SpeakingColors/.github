# Contributing

This project is open source so you can read it, use it, learn from it and fork it. Forks are welcome, have fun.

It is not open to outside contributions. Pull requests, patches and feature requests are not accepted, and nothing from outside will be merged into this repository. If you want to change or extend it, make it your own in a fork.

Found a security problem? Please report it privately through the repository's Security tab, not in public.
